Capabilities are the unit of permission. Grant them by name or glob in the
[permission matrix](/docs/integration/permissions). `GET /v1/capabilities` returns the live list
with the roles allowed to use each one.

## Write capabilities

These create drafts and follow the [save mode](/docs/assistant/save-modes).

| Name | Example message | Record |
|---|---|---|
| `record_collection` | "Ahmet Yılmaz'dan 5.000 TL havale tahsilat" | `collection` with invoice allocations |
| `record_payment` | "Demir Ltd'ye 12.500 TL ödeme yaptım" | `payment` |
| `record_expense` | Photo / PDF of a receipt, or a UBL-TR e-invoice XML | `expense` with lines and VAT |
| `create_order` | "Yıldız Market'e 10 koli A4 kağıt siparişi" | `order` with product lines |
| `import_bank_statement` | A bank statement (CSV, Excel, PDF) | `batch` of matched movements |
| `repeat_last` | "her zamanki gibi", "her zamanki gibi 3.000" | Same kind as the user's last record |

## Plugins

Company-specific capabilities (`x_…`) declared in the settings are listed and permissioned the
same way. See [Plugins](/docs/integration/settings#plugins).

## Chained commands

"Ahmet'ten 5.000 tahsilat **ve** bakiyesini göster" runs both capabilities in order, each with its
own permission check and save mode.
